## 1. 概述

Droidvisor 是一款基于 Android AVF (Android Virtualization Framework) 的虚拟机管理应用，支持在 Android 设备上运行 Debian 虚拟机和 Docker 容器。

### 1.1 主要功能

- **虚拟机管理**：创建、启动、停止、重启、删除虚拟机
- **多模板支持**：Debian Standard、Docker Host、Alpine Minimal
- **Docker 集成**：原生 Docker Dashboard，支持容器和镜像管理
- **备份管理**：完整备份和增量备份，一键恢复
- **网络配置**：NAT、桥接、主机模式，端口转发

### 1.2 系统要求

- **Android 版本**：Android 13 (API 33) 或更高版本
- **设备要求**：支持 AVF (Android Virtualization Framework)
- **存储空间**：取决于虚拟机数量，建议预留 10GB 以上

## 2. 快速入门

### 2.1 首次使用

1. **检查权限**
   - 应用启动后自动检测 AVF 权限
   - 若提示权限不足，请前往系统设置开启

2. **检查设备能力**
   - 应用会自动检测设备是否支持：
     - AVF (Android Virtualization Framework)
     - pKVM (Protected VM)
     - Vsock (Virtual Socket)

3. **创建第一台虚拟机**
   - 点击「VM 管理」页面中的「+」按钮
   - 选择虚拟机模板
   - 配置资源（内存、CPU、磁盘）
   - 点击「创建」

### 2.2 基本操作流程

```
创建 VM → 启动 VM → 使用 VM → 停止 VM → (可选) 删除 VM
```

## 3. 虚拟机管理

### 3.1 创建虚拟机

1. 进入「VM 管理」页面
2. 点击右下角「+」按钮
3. 填写虚拟机配置：

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| 名称 | 虚拟机的显示名称 | - |
| 模板 | 选择预定义模板 | Debian Standard |
| 内存 | 分配给 VM 的内存大小 | 2 GB |
| CPU | 分配给 VM 的 CPU 核心数 | 2 |
| 磁盘 | VM 的虚拟磁盘大小 | 10 GB |
| 网络模式 | VM 的网络连接方式 | NAT |

4. 点击「创建」按钮
5. 等待虚拟机创建完成

### 3.2 启动虚拟机

1. 在「VM 管理」页面找到目标虚拟机
2. 点击虚拟机卡片或「启动」按钮
3. 等待虚拟机启动完成（状态变为「运行中」）
4. 可通过终端界面访问 VM

### 3.3 停止虚拟机

1. 在虚拟机运行状态下，点击「停止」按钮
2. 确认停止操作
3. 等待虚拟机优雅关闭

### 3.4 重启虚拟机

1. 在虚拟机运行状态下，点击「重启」按钮
2. 确认重启操作
3. 等待虚拟机重启完成

### 3.5 删除虚拟机

1. 在「VM 管理」页面找到目标虚拟机
2. 点击「删除」按钮
3. 确认删除操作（注意：删除前请确保已备份重要数据）

### 3.6 查看虚拟机详情

1. 点击虚拟机卡片进入详情页面
2. 查看以下信息：
   - 基本信息（名称、模板、创建时间）
   - 资源使用（内存、CPU、磁盘）
   - 网络配置
   - 运行状态

## 4. Docker 集成

### 4.1 使用 Docker Host 模板

1. 创建虚拟机时选择「Docker Host」模板
2. 该模板预装 Docker Engine，可直接使用 Docker 命令

### 4.2 Docker Dashboard

进入「Docker Dashboard」页面，管理容器和镜像：

#### 容器管理

| 操作 | 说明 |
|------|------|
| 查看容器列表 | 显示所有容器及状态 |
| 启动容器 | 启动已停止的容器 |
| 停止容器 | 停止运行中的容器 |
| 暂停容器 | 暂停容器运行 |
| 恢复容器 | 恢复暂停的容器 |
| 删除容器 | 删除容器（可选强制删除） |

#### 镜像管理

| 操作 | 说明 |
|------|------|
| 查看镜像列表 | 显示所有镜像 |
| 拉取镜像 | 从 Docker Hub 拉取镜像 |
| 删除镜像 | 删除本地镜像（可选强制删除） |

#### 资源监控

- CPU 使用率
- 内存使用情况
- 网络 I/O 统计

### 4.3 Docker 命令行

在终端界面中可以直接使用 Docker 命令：

```bash
# 查看容器
docker ps

# 查看镜像
docker images

# 拉取镜像
docker pull nginx

# 运行容器
docker run -d nginx

# 停止容器
docker stop <container_id>
```

## 6. 网络配置

### 6.1 网络模式

| 模式 | 说明 | 适用场景 |
|------|------|----------|
| NAT | 默认模式，VM 通过主机转发访问外部网络 | 通用场景 |
| 桥接 | VM 直接连接到物理网络 | 需要独立 IP |
| 主机模式 | VM 共享主机网络命名空间 | 调试场景 |

### 6.2 静态 IP 配置

1. 进入虚拟机详情页面
2. 点击「网络配置」
3. 启用「静态 IP」
4. 输入 IP 地址、子网掩码、网关
5. 保存配置

### 6.3 DNS 配置

1. 进入虚拟机详情页面
2. 点击「网络配置」
3. 在「DNS 服务器」中添加 DNS 服务器地址
4. 保存配置

### 6.4 端口转发

1. 进入虚拟机详情页面
2. 点击「网络配置」
3. 点击「添加端口转发」
4. 配置协议（TCP/UDP）、主机端口、VM 端口
5. 保存配置

### 6.5 MTU 设置

1. 进入虚拟机详情页面
2. 点击「网络配置」
3. 修改 MTU 值（默认 1500）
4. 保存配置

## 9. 故障排除

### 9.1 常见问题

#### Q: 虚拟机无法启动？

**可能原因**：
- 设备不支持 AVF
- 资源不足（内存/磁盘）
- VM 配置错误

**解决方法**：
1. 检查设备是否支持 AVF
2. 确认系统有足够资源
3. 检查 VM 配置是否正确

#### Q: Docker 连接失败？

**可能原因**：
- Docker 服务未启动
- 网络连接问题
- Vsock 通信失败

**解决方法**：
1. 确保 VM 已启动且 Docker 服务运行中
2. 检查网络配置
3. 重启 VM

#### Q: 备份恢复失败？

**可能原因**：
- 备份文件损坏
- 磁盘空间不足
- VM 状态异常

**解决方法**：
1. 检查备份文件完整性
2. 确认有足够磁盘空间
3. 确保 VM 处于停止状态

### 9.2 日志查看

1. 进入「设置」
2. 点击「日志查看」
3. 选择日志级别过滤
4. 查看详细日志信息
